# Python, Data Analysis & Machine Learning Tasks

A collection of Python projects built to practice **API integration, data analysis, visualization, NLP, and machine learning**.

The repository contains four independent projects, each focusing on a different practical use case.

## Projects

### 1. API Integration & Data Visualization

**File:** `Task1.py`

Fetches weather data for multiple cities using the OpenWeather API, processes the JSON response, and visualizes the results.

#### Key Features

* REST API integration
* JSON data processing
* Pandas DataFrame analysis
* Weather comparison and visualization
* API error handling

#### Technologies

Python, Requests, Pandas, Matplotlib, Seaborn

#### Workflow

```text
Weather API → JSON Response → DataFrame → Analysis → Visualization
```

---

### 2. Sales Data Analysis & Reporting

**File:** `Task2.py`

Processes a sales dataset to analyze revenue, monthly trends, products, and regions. The results are exported to CSV and summarized in a PDF report.

#### Key Features

* Sales data processing and analysis
* Revenue and trend analysis
* Product and regional comparisons
* CSV export
* Automated PDF report

#### Technologies

Python, Pandas, NumPy, Matplotlib, ReportLab

#### Workflow

```text
Sales Data → Data Processing → Analysis → Visualization → Reports
```

---

### 3. NLP Intent Classification Chatbot

**File:** `Task3.py`

A simple NLP-based chatbot that analyzes user input and identifies the most relevant intent using text preprocessing, TF-IDF, and cosine similarity.

#### Key Features

* Text preprocessing
* Tokenization and lemmatization
* TF-IDF vectorization
* Cosine similarity
* Intent-based responses

#### Technologies

Python, NLTK, Scikit-learn, NumPy

#### Workflow

```text
User Input → Preprocessing → TF-IDF → Similarity → Intent → Response
```

---

### 4. SMS Spam Classification

**File:** `Task4.py`

An end-to-end machine learning project using the **UCI SMS Spam Collection dataset** to classify messages as spam or legitimate.

#### Key Features

* Data cleaning and preprocessing
* TF-IDF and CountVectorizer
* Multiple classification models
* Model comparison and evaluation
* Hyperparameter tuning
* Model serialization

#### Machine Learning Models

* Naive Bayes
* Support Vector Machine
* Logistic Regression
* Random Forest

#### Technologies

Python, Pandas, NumPy, NLTK, Scikit-learn

#### Workflow

```text
Dataset → Preprocessing → Feature Extraction → Training → Evaluation → Model
```
